# Лабораторна робота №3

**Тема.** Реалізація обробки виключень, модульності та документації в проектах Python.

Пакет `meter_lab` обчислює середню температуру за списком показників і порівнює її з верхньою межею з JSON-конфігурації. Демонстрація послідовно запускає контрольні приклади для чотирьох завдань.

## Запуск

Потрібен Python 3.10 або новіший. Зовнішніх залежностей немає, тому встановлювати пакети з `requirements.txt` не потрібно.

Відкрийте термінал у папці `lab-03-exceptions` та виконайте команду.

```powershell
py -3 -m meter_lab
```

У Linux і macOS використайте `python3 -m meter_lab`. Якщо у Windows доступна команда `python`, можна запустити `python -m meter_lab`.

Щоб перевірити завдання окремо, додайте параметр `--task` з номером від 1 до 4.

```powershell
py -3 -m meter_lab --task 2
```

## Що показує демонстрація

| Завдання | Що перевіряється |
| --- | --- |
| 1 | Перетворення `"3"` і `"три"` на ціле число, читання наявного та відсутнього файлів, обчислення середнього для коректних даних, тексту й нульової кількості. |
| 2 | Середня температура 22 °C при межі 25 °C, порожній список, відсутній і пошкоджений JSON, перевищення межі з повторним `raise` після запису до журналу. |
| 3 | Три форми імпорту й перевірка фактичних імен після `from meter_lab import *`. |
| 4 | Документація функції `check_readings` через `help()`, її ім'я, текст документації та анотації типів під час виконання. |

У папці `samples` зберігаються вхідні файли. `broken_settings.json` містить навмисну синтаксичну помилку для перевірки `JSONDecodeError`. Файли `missing_temperatures.txt` і `missing_settings.json` також навмисно відсутні.

## Будова пакета

- `meter_lab/__main__.py` передає керування консольній демонстрації.
- `meter_lab/demo.py` містить сценарії та обробку аргументу `--task`.
- `meter_lab/errors.py` описує базовий виняток `MeterError` і три його підкласи.
- `meter_lab/io_tools/` відповідає за читання UTF-8 і перетворення текстових чисел.
- `meter_lab/service/` завантажує конфігурацію, перевіряє вхідні значення та обчислює середню температуру.
- `meter_lab/__init__.py` зберігає перелік публічних імен пакета.
