## Запуск у Windows

Відкрийте PowerShell у каталозі проєкту в терміналі Visual Studio або VS Code.

```powershell
py -3 --version
py -3 main.py
```

Якщо команда `py` відсутня, але Python встановлено, замініть `py -3` на `python`.
Для Linux та macOS використовуйте `python3`.

Кожне завдання запускається окремо:

```powershell
py -3 main.py --task 1
py -3 main.py --task 2
py -3 main.py --task 3
py -3 main.py --task 4
py -3 main.py --task 5
```

Інший текст, поріг та каталог результатів:

```powershell
py -3 main.py --task 3 --text "data/text.txt" --threshold 2 --output results
py -3 main.py --task 5 --repeats 5
py -3 main.py --help
```

Типовий вхідний файл знаходиться відносно main.py, тому запуск з іншого
поточного каталогу також працює. Власні шляхи рахуються від поточного каталогу.

## Файли

| Файл | Призначення |
| --- | --- |
| main.py | Реалізація п'яти завдань та параметри запуску |
| data/text.txt | Відтворюваний вхідний текст UTF-8 |
| tests/test_main.py | Перевірки результатів і граничних випадків |
| example_results/ | Реальні CSV, частоти, вивід і параметри контрольного запуску |
| requirements.txt | Зовнішніх залежностей немає |
| .gitignore | Виключення середовищ, кешів, секретів та локальних результатів |

Після запуску створюється каталог results:
frequencies.tsv містить частоти слів, benchmark.csv - середні, мінімальні
та максимальні часи, benchmark_raw.csv - окремі повтори в секундах,
environment.json - версію Python, платформу та параметри експерименту.
Каталог results виключено з Git. Каталог example_results уже містить
контрольні результати CPython 3.12.14 на Linux x86_64. На іншому комп'ютері
часи відрізнятимуться; власні результати зберігаються окремо в results.

## Правила обробки тексту

NFC нормалізація, casefold для регістру, апострофи ’ ʼ ‘ перетворюються на '.
Регулярний вираз виділяє слова з Unicode-символів класу \w, крім \d та _;
апостроф допускається всередині слова. Цифри, підкреслення, дефіси та
розділові знаки розділяють слова. Для навчального тексту це літери
української та латинської абеток. Сортування за ключем використовує порядок
Unicode, а не словникове сортування української локалі.

## Методика експерименту

n = 100, 1000, 10000. Для пошуку створюються list, set та dict з ключами
від 0 до n-1. Шукається наявне значення n-1 наприкінці списку.
Кожен блок пошуку містить 10000 операцій, типово виконується 5 повторів.
Для видалення дублікатів вхід [i // 2 for i in range(n)] має рівно n/2
унікальних значень. Обидва алгоритми здійснюють один прохід.
Кількість повних проходів у блоці: max(1, 10000 // n).

timeit.repeat вимірює тільки операції, без підготовки входу, друку та
записування файлів. Створення результуючого list/set входить у вимірювання
побудови унікальних значень. Час блоку ділиться на кількість операцій;
таблиця показує середнє, мінімум і максимум у мікросекундах.
Малі вимірювання залежать від навантаження ОС, кешу та реалізації Python.
Очікувана складність: list_in O(n), set_in/dict_in у середньому O(1),
unique_list O(n^2), unique_set у середньому O(n). Це не гарантії
найгіршого випадку для хешованих структур.
