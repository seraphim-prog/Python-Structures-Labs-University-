## Запуск

Потрібен Python 3.10 або новіший. Усі скрипти використовують стандартну бібліотеку Python.
Відкрийте `practice-01` у VS Code та запускайте потрібний файл у PowerShell.
Якщо відкрито корінь спільного репозиторію, спочатку виконайте `cd practice-01`.

| Завдання | Команда | Приклад введення по одному рядку |
| --- | --- | --- |
| 1.1 Вирази | `py -3 practical_01_task_1_1.py` | `3`, `4`, `5` |
| 1.2 Типи | `py -3 practical_01_task_1_2.py` | `-3,75`, `Ірина`, `7` |
| 2.1 ЄКТС | `py -3 practical_01_task_2_1.py` | `60` |
| 2.2 Трикутник | `py -3 practical_01_task_2_2.py` | `5`, `3`, `4` |
| 3.1 Цикл `for` | `py -3 practical_01_task_3_1.py` | `5` |
| 3.2 Калькулятор | `py -3 practical_01_task_3_2.py` | `10 // 3`, `2 ** 3`, `7 / 0`, `history`, `quit` |

На Windows без `py` використовуйте `python`. На Linux і macOS замініть `py -3` на `python3`.
У `practical_01_common.py` містяться спільні функції зчитування чисел і перевірки сторін.

## Особливості введення

- Програми з дійсними числами приймають десяткову крапку та кому.
- Типи трикутників перевіряються в такому порядку: рівносторонній, прямокутний, рівнобедрений, різносторонній. Для прямого кута перевіряється абсолютна й відносна похибка `1e-9`.
- `n` у завданні 3.1 має бути невід’ємним цілим числом. Для `n = 0` маємо `0! = 1`, `H(0) = 0` і порожню таблицю. Вивід таблиці має `n²` клітинок.
- Калькулятор приймає оператор між двома пробілами, наприклад `10 % 3`. `history` показує успішні обчислення поточного запуску, а `quit` завершує роботу.
- `id(список)` у завданні 1.2 ідентифікує об’єкт у поточному запуску. Це значення може змінюватися між запусками.
