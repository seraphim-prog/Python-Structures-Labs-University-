## апуск

отрібен Python 3.10 або новіший. роєкт використовує тільки стандартну бібліотеку. становлення пакетів не потрібне.

ідкрийте папку `lab-02-oop` у VS Code та запустіть у терміналі PowerShell:

```powershell
py -3 main.py
```

Якщо термінал відкритий у корені спільного репозиторію, перейдіть до папки роботи командою `cd lab-02-oop`. а Linux і macOS використовуйте `python3 main.py`. а Windows без команди `py` використовуйте `python main.py`.

ожне завдання можна запустити окремо:

```powershell
py -3 main.py --task 1
py -3 main.py --task 2
py -3 main.py --task 3
py -3 main.py --task 4
py -3 main.py --task 5
```

## авдання

|  | одуль | Що демонструє |
| --- | --- | --- |
| 1 | `task1_vehicles.py` | Спільний метод розрахунку часу поїздки для велосипеда, самоката й фургона. |
| 2 | `task2_sensor.py` | ластивості температурного датчика, валідацію та перетворення приватного імені. |
| 3 | `task3_vector.py` | редставлення, арифметику, порівняння, розмірність і довжину двовимірного вектора. |
| 4 | `task4_orders.py` | онтракт способу доставки та делегування обчислень у замовленні. |
| 5 | `task5_queue.py`, `task5_urgent.py` | міну алгоритму впорядкування черги друку під час виконання. |

Точкою входу є `main.py`. ля розширення черги друку додано `UrgentFirst` в окремому модулі. ерга `PrinterQueue` викликає задану стратегію через спільний метод `order`.

 завданнях 1, 2 і 4 окремі фрагменти навмисно викликають винятки. рограма перехоплює їх і продовжує виконання. очаткові дані задані в демонстраціях, тому результати відтворюються на іншому комп’ютері.
