# ЛБ №4. Графічний інтерфейс з PyQt6

**Журнал навчальних сесій** записує тему, категорію, тривалість і складність занять, показує прогрес добової цілі та експортує журнал у JSON. До цілі зараховуються тільки завершені сесії.

## Запуск

Потрібен Python 3.10 або новіший. Виконуйте команди з папки `lab-04-pyqt6`.

Windows, PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Linux і macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Для стандартного вигляду Qt передайте аргумент `--plain` після `main.py`. Вигляд можна також змінювати під час роботи через **Інструменти → Оформлення QSS**.

## Перевірка завдань

1. Змініть розмір вікна. Поля форми та панель журналу залишаються доступними при мінімальному розмірі вікна.
2. Спробуйте додати запис з порожньою темою або тривалістю 0 хв. Далі введіть тему, оберіть категорію, тривалість від 5 до 240 хв і складність. Перемкніть прапорець завершення, перевірте чернетку та додайте сесію.
3. Натисніть **Ctrl+N**, щоб скинути форму, і **Ctrl+S**, щоб відкрити експорт. Ті самі дії є в меню **Файл** і на панелі інструментів. Після підтвердження експорту файл містить параметри журналу та список занять у кодуванні UTF-8.
4. Після додавання сесії перевірте список, шкалу цілі та рядок стану. Натисніть **Скинути**. Поля повернуться до початкових значень, а чернетка оновиться один раз. Збережені в поточному сеансі записи залишаться в журналі.
5. Відкрийте **Ціль на день** (Ctrl+G) і змініть кількість хвилин. У **Параметрах журналу** (Ctrl+,) задайте назву та ціль, підтвердьте або скасуйте зміни. Перемкніть QSS, щоб порівняти вигляд вікна.

Дані зберігаються в пам’яті під час роботи застосунку. Для збереження на диск використайте **Файл → Експорт JSON…**.

## Файли проєкту

| Файл | Призначення |
|---|---|
| `main.py` | Цикл подій, головне вікно, дії меню та стандартні діалоги |
| `widgets.py` | Форма введення, панель журналу та власні сигнали |
| `journal.py` | Моделі даних, валідація сесії й експорт JSON |
| `dialogs.py` | Модальний діалог параметрів |
| `style.qss` | Глобальне оформлення та стилі за objectName |
