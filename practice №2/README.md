## Запуск

Відкрийте папку `practice-02` у VS Code. Скрипти працюють у Python 3.10 або новішому та використовують стандартну бібліотеку. Для запуску у PowerShell виберіть потрібну команду.

| Завдання | Команда | Що показує |
| --- | --- | --- |
| 1.1 | `py -3 practical_02_task_1_1.py` | Циклічний діапазон і вичерпання ітератора. |
| 1.2 | `py -3 practical_02_task_1_2.py` | Незалежні обходи групи, пари та топ студентів. |
| 2.1 | `py -3 practical_02_task_2_1.py` | Прогресії, Фібоначчі, Коллатц і `yield from`. |
| 2.2 | `py -3 practical_02_task_2_2.py` | Фільтрація оцінок і середні за предметами. |
| 3.1 | `py -3 practical_02_task_3_1.py` | Розміри об’єктів, середній час `sum()` і вирази-генератори. |

На Windows без `py` використовуйте `python`, а на Linux або macOS — `python3`.
Скрипти беруть демонстраційні дані з умови. З клавіатури нічого вводити не потрібно.

## Особливості реалізації

- `CyclicRange` підтримує додатний і від’ємний крок. Після вичерпання `next()` піднімає `StopIteration`.
- `StudentGroup` створює новий ітератор на початку кожного обходу. `top_students()` повертає ітератор по відсортованих записах.
- Геометрична прогресія видає значення до включної межі `limit`. Для послідовностей, що залишаються під межею, використовуйте `itertools.islice()`.
- Середній бал у завданні 2.2 враховує всі коректні оцінки від 0 до 100, незалежно від порога виводу 75.
- `sys.getsizeof()` вимірює розмір самого об’єкта. `timeit.timeit()` вимірює п’ять викликів, сумарний час ділиться на п’ять. На іншій системі результати можуть відрізнятися.
