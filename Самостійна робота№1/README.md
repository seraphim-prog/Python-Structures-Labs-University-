## Запуск

Відкрийте папку `self-study-01` у VS Code і виконайте в терміналі PowerShell:

```powershell
py -3 main.py
```

На Windows без команди `py` використовуйте `python main.py`.
На Linux або macOS запустіть `python3 main.py`.
Програму перевірено на Python 3.12. Використано стандартну бібліотеку.

## Команди меню

| Команда | Дія |
| --- | --- |
| `1` | Факторіал цілого числа `n ≥ 0`. |
| `2` | Площа й периметр прямокутника, площа трикутника, площа круга й довжина кола. |
| `3` | Вивід історії та прикладів `list`, `tuple`, `dict`. |
| `4` | Клас-ітератор обходить усі записи. Генератор через `yield` видає геометричні записи. |
| `m` | Повторно відобразити меню. |
| `0` | Завершити програму. |

## Приклад

Введіть `1`, потім `5`, щоб отримати `5! = 120`. Далі введіть `2`,
виберіть прямокутник (`1`) і задайте сторони `3`, `4`. Площа дорівнює `12.00`,
периметр — `14.00`. Команда `4` покаже обидва записи через ітератор,
а генератор видасть тільки запис про прямокутник.

Розміри мають бути скінченними додатними числами. Можна вводити десяткову
кому або крапку. Історія зберігає успішні обчислення поточного запуску.
